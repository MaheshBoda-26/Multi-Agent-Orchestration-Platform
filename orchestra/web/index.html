The loop

Five moves. Zero surprises.

Every run takes the same path — so you always know where your work is, what it cost, and who's accountable.

01 — Plan

A supervisor decomposes. Memory tilts the plan.

Every request becomes a validated dependency graph. Lessons from past runs steer it — and a low-confidence plan stops for a human before a single token is spent.

supervisor.planmemory.retrieve
02 — Execute

Parallel specialists, jailed tools.

Subtasks fan out concurrently inside per-task workspaces — allowlists, rate limits and a full audit trail. Tool output arrives quarantined as untrusted data.

Send ×N paralleltool_calls audit
03 — Review

A reviewer gates every output.

Nothing reaches synthesis unreviewed. Correctness, completeness, format and sources are scored; a rejection goes back with feedback — once — then escalates.

reviewer.reviewretry cap 2
04 — Hold

Humans hold the veto. Durably.

Sensitive calls pause the run as durable approval rows. Decide from any browser, hours later, after a worker restart. No timeouts, ever.

awaiting_humanno approval timeout
05 — Remember

Every run leaves a lesson.

Post-run extraction stores one vector-embedded lesson per task. The next similar request retrieves it — so the system compounds. Inspect or erase anything.

Trust

Built to be audited.

Six guarantees, enforced in code — and traced to a test.

S1 Workspace jail File tools cannot see outside the per-task workspace — symlinks and sibling-prefix tricks included.realpath + commonpath
S2 HTTP allowlist Domain allowlist, scheme limits, private-address blocking on every redirect hop.per-hop SSRF checks
S3 Sandboxed code Read-only rootfs, CPU/memory/PID caps, tmpfs scratch, timeout kill.docker, no network
S4 Injection defenses Tool output is quarantined; instruction-like patterns are flagged. Text inside frames is data, never commands.UNTRUSTED DATA frame
S5 Human approval gate code_execute, http_get and file_write stop the run until a human signs that exact call.signature-keyed
S6 Full audit Every tool call and model call recorded with arguments, outputs, latency and cost.tool_calls + spans
Get started

Describe it. It's running.

One line in, a supervised pipeline out — planned, executed, reviewed and remembered.

Durability claim verified by the kill/resume integration test: the worker process is terminated mid-run (SIGKILL) and the run resumes from its last checkpoint with no repeated steps.

Security and evaluation scores are read from this repository's own result files and reproduced by CI.
